# Figure gallery — polymer–ceramic thermal conductivity dataset (260 rows, 95 papers)

All charts are generated by `work/final_figures.py` directly from the final dataset (`work/rows_raw.jsonl` / `thermal_conductivity_dataset.csv`). No synthetic data.

| File | Chart |
|---|---|
| `01_k_distribution.png` | Histogram of k_composite (W/m·K, log x-axis) with median marker — heavy right tail from highly loaded BN networks. |
| `02_rows_per_year.png` | Bar chart of extracted rows per publication year (1997–2026). |
| `03_rows_by_filler.png` | Horizontal bar chart of rows by normalized filler material (h-BN, BNNS, BN, AlN, hybrids…). |
| `04_rows_by_matrix.png` | Bar chart of rows by matrix polymer (epoxy-based vs optional matrices). |
| `05_confidence_value_source.png` | Two-panel breakdown: rows by confidence (High/Medium) and by value source (text/table/figure). |
| `06_k_vs_loading.png` | Bonus: k_composite vs filler loading (wt% or vol% as recorded), log y-axis, colored by filler family. |
